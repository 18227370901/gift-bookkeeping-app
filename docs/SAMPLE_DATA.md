## 一、样例库定位与说明

随仓库分发的根目录 `gift_bookkeeping.db` 是一套去隐私化、高仿真度且零明文落盘的 SQLite 样例库：
- **开发与联调参考**：用于本地快速预览前端 UI 渲染、图表走势、导出功能及人情对账闭环；
- **生产隔离设计**：生产部署时（通过 `./run.sh` 或首次初始化），系统会自动在 `data/` 目录下生成纯净的全新运行库（仅创建单一初始管理员 `admin`），演示数据绝不会污染生产环境。

## 二、样例数据资产构成

样例库内置了覆盖典型家庭全生命周期的人情往来记录：

1. **礼金记账明细 (151 条高仿真记录)**：
   - **收礼 107 条**（合计约 13.1 万元）：涵盖婚宴、满月酒、百日宴、周岁宴、寿宴、升学宴、乔迁、开业、生日等典型人情场景，部分记录已与专属宴席台账绑定；
   - **随礼 42 条**（合计约 2.3 万元）：涵盖随礼婚宴、白事、生日、乔迁等往来场景，与收礼数据闭环形成完整的人情对账（如亲友「柏楚安」同时存在收礼与随礼，可直观体验「待还礼/待补礼」状态流转）；
   - 姓名、联系方式、地址均为虚拟数据，无真实个人隐私。
2. **专属宴席大账本 (3 场典型办席)**：
   - `2026年 儿子大婚答谢喜宴`（事由：结婚，预算 6.8 万，花销 5.9 万，关联收礼明细）；
   - `2026年 乔迁新居阖家福酒`（事由：乔迁，预算 1.5 万，花销 1.2 万）；
   - `2026年 老父亲七十古稀寿宴`（事由：寿宴，预算 2.8 万，花销 2.56 万）。
3. **亲友纪念日备忘 (6 条预警示例)**：
   - 涵盖父母寿辰、结婚周年纪念日、挚友生日、升学宴等；虚拟手机号全量脱敏（`13800000001`~`13800003002`）。
4. **消息通知与推送通道配置 (3 组标准示例)**：
   - 企业微信官方智能机器人（WebSocket 长连接 openws 模式）；
   - 企业微信群机器人（Webhook URL 模式）；
   - 钉钉群机器人（Webhook URL 模式）；
   - *安全说明*：推送密钥与凭证默认为空且处于已禁用状态（`is_enabled=0`）。
5. **大账本只读共享外链 (2 组)**：
   - 儿子大婚与宝宝满月对外分享外链，口令（`123456` / `666888`）通过底层 AES-256-GCM 强加密存储。
6. **WebDAV 外部云端备份配置**：
   - 预设坚果云标准 WebDAV 接入示例（演示账号，密码默认为空，默认禁用自动备份）。

## 四、敏感数据零明文安全防护机制

系统在底层数据持久化层全面贯彻**零明文落盘**与**深度脱敏**策略：
- **底层对称加密 (AES-256-GCM)**：用户添加的所有第三方敏感凭据（企业微信 Bot Secret、Webhook 签名密钥、WebDAV 密码、大账本分享口令等）均在落盘前自动通过 AES-256-GCM 进行强加密持久化存储；
- **ORM 透明加解密**：上层业务通过 Python ORM `@property` 自动透明解密，对业务无感知；
- **日志全自动递归脱敏**：系统写入数据库 `webhook_logs` 与 `operation_logs` 的请求载荷与响应体均经过递归扫描，涉及 `secret`、`token`、`pass`、`key`、`auth` 的字段一律自动替换为 `***MASKED***`。

## 五、样例库维护与推送前 9 项核查准则

随仓库分发的样例库 `gift_bookkeeping.db` 必须保持无任何真实隐私与真实生产密钥。每次向远程仓库推送前，必须严格核查以下 9 项红线规则：

| # | 检查项 | 验证规则 |
|:---|:---|:---|
| 1 | **真实用户名** | `users` 表绝对不得出现任何开发人员真实账号或真实组织标识 |
| 2 | **冻结演示用户** | `demo_user_frozen` 必须存在且 `is_active=0`（保持冻结状态） |
| 3 | **会话令牌** | `users` 表全部 `session_token` 字段必须重置为空 |
| 4 | **WebDAV 密码** | `backup_configs.webdav_password` 必须为空 |
| 5 | **WebDAV 地址** | `backup_configs.webdav_url` 必须为通用公共端点 `https://dav.jianguoyun.com/dav/` |
| 6 | **Webhook 密钥** | `webhook_configs` 的 `secret_token` 与 `bot_secret` 必须为空 |
| 7 | **Webhook 地址** | `webhook_configs.webhook_url` 必须包含 `SAMPLE` / `DEMO` / `EXAMPLE` 占位样例标记 |
| 8 | **注册邀请码** | `registration_tokens` 表必须为空 |
| 9 | **分享口令** | `shared_ledger_links.access_password` 解密后必须为公开演示口令 `123456` / `666888` |

> 💡 **两版一致性要求**：传统原生部署版与 Docker Compose 版的样例库 `gift_bookkeeping.db` 必须保持字节级一致（MD5 校验和相同）。
